# Login artwork

Drop up to three photographs here and the sign-in screen uses them automatically:

    car-1.jpg   car-2.jpg   car-3.jpg

Nothing breaks if they are absent — the panel falls back to a designed graphic.

## What works well

- Everyday stock, not luxury: Swift, i20, Baleno, Nexon, Amaze, Dzire, Creta.
- Landscape, three-quarter front view, roughly 2400×1600 or larger.
- Shot outdoors in daylight; avoid busy backgrounds and visible number plates.
- Save as JPEG, quality ~80, ideally under 400 KB each so sign-in stays fast.

## Licensing

Use photographs you own, or ones explicitly licensed for commercial use
(Unsplash and Pexels both permit it). Do not use images pulled from a search
engine or a dealer's website — that is someone else's copyright.
