## Conventions

- **Money** is stored as integer **paise** in `*Paise` columns. `₹1,234.50` is `123450`.
- **Timestamps** (`createdAt`, `updatedAt`, `*At`) are ISO-8601 UTC strings.
- **Business dates** (`date`, `*Date`, `*On`) are date-only `YYYY-MM-DD` in Asia/Kolkata.
- **Booleans** are the strings `TRUE` / `FALSE`.
- **Identifiers** are UUIDs. Row numbers are never identifiers.
- **Phone numbers and references** are text, preserving leading zeros.

Every tab begins with the same eight audit columns:

| Column | Meaning |
| --- | --- |
| `id` | UUID primary key. Stable for the life of the record. |
| `createdAt` | ISO timestamp of creation. |
| `updatedAt` | ISO timestamp of the last write. |
| `version` | Incremented on every write; a mismatched version rejects the edit as stale. |
| `operationId` | Operation that produced this write; used for retry-safety and reconciliation. |
| `createdBy` | Email of the staff member who created the row. |
| `updatedBy` | Email of the staff member who last wrote the row. |
| `archived` | Soft delete. Financial records use void/reversal instead. |
